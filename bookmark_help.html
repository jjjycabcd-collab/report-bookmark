소스코드 분석 리포트

📑 PDF 연구보고서 책갈피 자동 생성기

Python과 Streamlit으로 작성된 본 프로그램은 PDF 문서의 텍스트, 폰트 사이즈, 좌표를 분석하여 계층화된 목차(Bookmark)를 자동으로 생성하는 강력한 도구입니다.

프로그램 개요

목적 및 용도

방대한 분량의 연구보고서나 공공문서 PDF 파일에 네비게이션용 책갈피(Bookmark/TOC)를 자동으로 삽입하는 웹 애플리케이션입니다. 사용자가 일일이 수동으로 목차를 만들 필요 없이, 문서 내부의 텍스트와 구조를 인공지능적으로 스캔하여 계층 구조(1-depth ~ 최대 5-depth)를 알아서 구성해 줍니다.

기술 스택 (Tech Stack)

  • UI 프레임워크: Streamlit
  • PDF 처리: PyMuPDF (fitz)
  • 패턴 인식: Python 정규표현식 (re)
  • 유사도 검사: RapidFuzz / Difflib

지원하는 스캔 모드

FULL_SCAN

문서 전체의 폰트 사이즈와 정규식을 분석하여 목차를 추출합니다.

TOC_BASED

문서 앞단의 '목차' 페이지를 우선 분석한 후 본문과 매칭합니다.

ALL

두 가지 모드를 동시에 실행하여 결과를 비교할 수 있게 합니다.

동작 절차 (알고리즘 흐름)

프로그램 내부에 구현된 5단계의 파이프라인 분석 과정입니다.

Step 1. 국문 목차 페이지 전용 탐색

문서 앞부분(최대 30페이지)을 스캔하여 '목차', '차례' 등의 키워드를 찾아 목차 영역을 식별하고, 해당 페이지의 텍스트를 추출해 1차 후보군을 형성합니다.

Step 2. 본문 좌표 추적 및 유효성 통제

Step 1에서 찾은 목차 항목들이 실제 본문(Body)의 어느 페이지, 어느 Y좌표에 위치하는지 find_anchor_in_page 함수로 매칭합니다.

Step 3. 본문 전체 스캔 (FULL_SCAN) 및 프로파일링

본문의 모든 텍스트 블록을 스캔하며 글자 크기(f_size), 폰트 속성(flags), 색상(color)을 프로파일링합니다. 각주, 표 안의 텍스트, 쓸모없는 문장(가비지 데이터)은 철저히 배제합니다.

Step 4. 시퀀스/페이지 역전 검증 (안전장치)

목차의 번호 순서(예: 1장 -> 2장)나 페이지 번호가 거꾸로 가는 현상(역전 현상)을 방지합니다. 폰트 프로필이 갑자기 달라지면 오탐으로 간주하여 필터링합니다.

Step 5. 유령항목 단일화 및 최종 트리 구성

목차 본문에는 없지만 필수적인 '표지', '제출문', '요약서', '참고문헌' 등을 최상위(1-depth)에 고정 배치하고, doc.set_toc()를 통해 PDF에 책갈피를 물리적으로 삽입합니다.

핵심 특징 (Key Features)

🇰🇷

한국어 연구보고서 특화 패턴 인식

제 1 장, 1.1.1, 가., (1) 등 한국어 공공/연구 문서에서 널리 쓰이는 복잡한 목차 넘버링 체계를 무려 14가지 이상의 정규표현식(Regex)으로 완벽하게 파싱합니다.

👻

유령 항목(Ghost Items) 스마트 처리

실제 문서의 '목차' 페이지에 등재되어 있지 않지만, 사용자가 반드시 필요로 하는 '표지', '요약문', '영문요약서(Summary)', '참고문헌' 등을 스스로 찾아내어 1-depth 항목으로 자동 추가합니다.

🛡️

가비지 데이터 및 노이즈 필터링

단순 본문 문장("~하였습니다.", "~할 수 있다"), 각주, 표(Table) 내부의 숫자, 그림 캡션(Fig 1.) 등을 목차로 오인하지 않도록 위치 기하학(BBox)과 형태소 어미 정규식을 통해 철저히 배제합니다.

🎛️

사용자 정의(Custom) 정규식 지원

문서마다 고유한 기호를 사용할 경우를 대비하여 Streamlit 사이드바를 통해 사용자가 1~3 Depth의 패턴(예: 1-1, [A] 등)을 직접 입력하여 강제 지정할 수 있는 유연성을 제공합니다.

제공되는 결과물

📥

완성된 PDF 파일 다운로드

기존 PDF 문서의 원본은 훼손하지 않고, 좌측 네비게이션 패널에 계층형 책갈피(TOC) 정보가 완벽하게 내장된 새로운 _bookmarked.pdf 파일을 제공합니다.

🖥️

실시간 추출 로그 (Terminal UI)

스트림릿 화면상에 개발자 친화적인 터미널 형태의 로그를 제공합니다. 추출 과정의 진척도, 에러 요소([점검]), 생성된 목차의 계층 트리를 시각적으로 렌더링합니다.

로그 출력 예시 (UI 시뮬레이션)

> 1. 국문 목차 페이지 전용 탐색 중... -> 3p에서 국문 목차를 성공적으로 찾았습니다. > 2. 본문 좌표 추적 및 상하 범주 유효성 통제 중... > 3. 본문 스캔(FULL_SCAN) 및 프로파일링 중... > 4. 시퀀스/페이지 역전 검증 중... > 5. 유령항목 단일화 및 최종 책갈피 트리 구성 중... 표지 (0p) 목차 (3p) 요약문 (5p) 제 1 장 서론 (12p) 1. 연구의 필요성 (12p) 2. 연구 목표 (15p) 제 2 장 본론 (20p) [점검] 1. 잘못 추출된 오타 항목 (25p) 참고문헌 (120p) 끝페이지 (125p)
